# System Engineering & DevOps

A collection of learning exercises focused on system engineering and DevOps. The current top-level project covers web infrastructure design: documenting how web systems are structured, distributed, secured, monitored, and scaled.

## Repository layout

- `web_infrastructure_design/` — infrastructure-design exercises, including simple, distributed, secured/monitored, and scaled web-stack scenarios.
- `web_infrastructure_design/README.md` — project-level notes.

The diagrams and explanations are study artifacts; review and adapt any design for your own requirements before using it in a real environment.
